# HoneySky White Board 部署与运维指南

适用版本：1.2.6.1（1.0.0–1.2.6 升级说明见第 8、9 节）｜ 面向学校机房管理员、企业 IT 运维与批量部署场景 ｜ 更新日期：2026-11-03

日常使用说明见 `docs/user-guide.md`，安装包清单与源码构建见 `README.md`。

## 1. 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809（10.0.17763）及以上、Windows 11；仅 x64，不支持 32 位与 ARM64 |
| 运行时 | 无需预装 .NET：发布物为**自包含**（自带 .NET 8 运行时与 WPF 组件） |
| 磁盘 | 安装后约 300 MB（自包含载荷）；用户数据按实际文档增长 |
| 显卡 | 支持 DirectX 9 及以上的显卡；软件渲染可用（性能降低） |
| 输入设备 | 鼠标、触摸屏、触控笔（压感需 Windows Ink 支持的数字笔） |
| 网络 | 可选。仅「网络授时」「问 AI（AI 助手）与讲台内问 AI」「DeepSeek 余额查询」需要网络，离线时自动回退/禁用 |
| 权限 | 安装与卸载需要管理员权限（perMachine）；日常运行**不需要**管理员权限 |

## 2. 部署形态选择

| 形态 | 适用 | 说明 |
| --- | --- | --- |
| EXE（Inno Setup） | 单机、少量机器、需要交互式卸载提示 | 图形向导，可静默 |
| MSI（WiX 5） | 域内组策略/Intune/SCCM 批量部署 | 标准 MSI，支持 `/qn` 静默与卸载 |
| 绿色便携版 zip | 机房漫游机、U 盘、无安装权限的临时机器 | 解压即用，数据写程序目录下 `Data\` |

同一台机器**只装一种**：EXE 与 MSI 同时安装会造成两套卸载信息与重复快捷方式。绿色版可与安装版共存，但要避免把便携目录放在 `Program Files`（不可写会回退到 `%LOCALAPPDATA%`）。

## 3. 静默安装

### 3.1 EXE 安装包（Inno Setup）

```bat
rem 静默安装到默认目录（C:\Program Files\HoneySky White Board）
HoneySkyWhiteBoard-1.2.6-win-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /LOG="%TEMP%\hswb-install.log"

rem 指定安装目录 + 不创建桌面图标（如安装脚本提供该任务）
HoneySkyWhiteBoard-1.2.6-win-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\Apps\HoneySky White Board" /LOG="%TEMP%\hswb-install.log"
```

- `/VERYSILENT` 无界面；`/SUPPRESSMSGBOXES` 不弹确认框；`/LOG=` 输出安装日志便于审计。
- 静默安装不会自动启动程序（`skipifsilent`）。
- 退出码：`0` 成功，`非 0` 失败（详见日志）。

### 3.2 MSI 安装包（WiX）

```bat
rem 静默安装（全机器）
msiexec /i "HoneySkyWhiteBoard-1.2.6-win-x64.msi" /qn /norestart ALLUSERS=1 /l*v "%TEMP%\hswb-msi-install.log"

rem 静默卸载
msiexec /x "HoneySkyWhiteBoard-1.2.6-win-x64.msi" /qn /norestart /l*v "%TEMP%\hswb-msi-uninstall.log"

rem 仅解包（不安装），用于分发前检查文件清单
msiexec /a "HoneySkyWhiteBoard-1.2.6-win-x64.msi" /qb TARGETDIR="D:\hswb-unpack"
```

- 退出码 `0` 成功；`3010` 成功但需要重启；`1603` 致命错误（多为权限/文件占用/安装包损坏）。
- 静默安装/卸载都不会弹「是否删除用户数据」的对话框，**用户数据一律保留**。

## 4. 文件关联（.hswb）

安装包注册 `.hswb` 文件关联（ProgId：`HoneySkyWhiteBoard.Document`），双击白板文档即可用本软件打开；主程序启动时解析命令行中的 `.hswb` 路径并直接打开该文档（文件不存在时只记录 WARN 日志并正常启动，不弹错）。

若企业策略禁止修改 HKCR/文件关联，安装仍可成功，只是双击文档时需「打开方式」手动指定 `HoneySkyWhiteBoard.exe`。

## 5. 数据位置与重定向

| 场景 | 数据根目录 |
| --- | --- |
| 安装版（默认） | `%LOCALAPPDATA%\HoneySky White Board\` |
| 绿色便携版 | `程序目录\Data\`（目录不可写时回退到 `%LOCALAPPDATA%`） |
| 显式指定 | 环境变量 `HONEYSKY_DATA_DIR`（优先级最高） |

子目录：`Documents`（文档与自动保存副本）、`Settings`（`settings.json`、`api-key.dat`）、`Cache`、`Thumbnails`、`Recovery`（异常恢复）、`Logs`（`app.log`，不含密钥）。

- 数据按**当前 Windows 用户**隔离：同机多账号各自独立；漫游配置文件会随用户漫游。
- 建议不要把 `HONEYSKY_DATA_DIR` 指到慢速网络盘（自动保存与缩略图缓存会明显变慢）；确需集中存储时，让用户把 `.hswb` 保存到网络盘，本地数据目录保持在本机。
- 备份策略：备份 `Documents` 目录即可覆盖全部用户文档；`Settings` 含 DPAPI 加密的 API Key，跨机器复制后不可解密（需在新机器重新填写）。

## 6. 卸载与数据保留策略

- 交互式卸载（控制面板/开始菜单/`msiexec /x` 带界面）会启动 `HoneySkyCleanup.exe`，询问是否**同时删除个人文档、设置和缓存**，**默认不勾选**（保留数据）。
- 静默卸载不弹任何窗口，直接保留用户数据。
- 确需批量清理用户数据时，在卸载后单独执行（需逐用户上下文或指定数据根）：

```bat
rem 只读检查（不删除任何文件），退出码 0 表示检查通过
"C:\Program Files\HoneySky White Board\HoneySkyCleanup.exe" --check-only --data-root "%LOCALAPPDATA%\HoneySky White Board"
```

清理工具只处理数据根目录下的 `Documents`/`Settings`/`Cache`/`Thumbnails`/`Recovery`/`Logs` 六个子目录，不会触碰其他路径；删除前有二次确认。

## 7. 网络与安全

| 能力 | 目标 | 协议/端口 | 关闭方式 |
| --- | --- | --- | --- |
| 网络授时 | `ntp.aliyun.com`（SNTP）及设置中的 HTTP 时间源 | UDP 123 / HTTPS 443 | 设置 → 时钟相关开关，或断网时自动回退系统时间 |
| 更新检测 | `api.github.com` 的 Release 接口及镜像回退 | HTTPS 443 | 全部失败时静默跳过，不影响使用；不自动下载安装 |
| 问 AI（AI 助手）与讲台内问 AI | 用户自行配置的 OpenAI 兼容服务 BaseUrl | HTTPS 443（按 BaseUrl） | 不配置即完全不发起请求（默认状态未配置） |
| DeepSeek 余额 | DeepSeek 官方域名（仅官方接口时） | HTTPS 443 | 设置 → AI → 关闭余额查询 |

- 程序**不包含**遥测、崩溃上报、广告或任何后台自动上传；未经用户点击「发送」不会上传图片与文字。
- API Key 使用 Windows DPAPI（当前用户范围）加密存储在 `Settings\api-key.dat`，日志中不输出。
- 程序未做代码签名：高安全环境（AppLocker/WDAC/SmartScreen）请按发布包 SHA-256 建立允许规则，或先行测试放行。

## 8. v1.2.6.1 升级部署（1.2.6 → 1.2.6.1；1.0.0–1.2.6 也可直接升至 1.2.6.1）

### 8.1 版本号规则（四段版本，务必注意）
- 1.2.6.1 是四段版本：AssemblyVersion / FileVersion 只接受 4 段，即 1.2.6.1（写成 1.2.6.1.0 会编译失败 CS7034）。
- Inno Setup 的 VersionInfoVersion 支持 1–4 段，1.2.6.1 原样写入安装包版本信息。
- **Windows Installer 只比较版本前三段**：1.2.6 与 1.2.6.1 在 MSI 看来是同一版本，覆盖安装依赖既有的 AllowSameVersionUpgrades="yes"。因此不要用 MSI 版本号判断“1.2.6.1 比 1.2.6 新”，也不要指望 MSI 会拦下 1.2.6.1 → 1.2.6 的降级。
- ProductCode 每版唯一（1.2.6.1 为 {278E9BFD-8116-4878-9EA2-7733D6C44432}），UpgradeCode {B7D41E2A-9C33-4F6B-8E21-5A0C3D9F6B14} 与 Inno AppId {A8E3F1C7-5B2D-4E9A-8C61-7F0B92D4E3A5} 保持不变。

### 8.2 EXE 就地升级
```
HoneySkyWhiteBoard-1.2.6.1-win-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /LOG="%TEMP%\hswb-upgrade-1261.log"
```
- 同一 AppId 就地覆盖，安装目录、快捷方式、.hswb 关联保持；用户数据目录默认不动。
- 静默卸载（/VERYSILENT）不弹清理对话框，直接保留 %LOCALAPPDATA%\HoneySky White Board 全部数据。

### 8.3 MSI 部署
```
msiexec /i "HoneySkyWhiteBoard-1.2.6.1-win-x64.msi" /qn /norestart /l*v "%TEMP%\hswb-msi-1261.log"
```
- 与 1.2.6 同 UpgradeCode：新 ProductCode 注册、旧 ProductCode 注销（MajorUpgrade afterInstallInitialize）。
- 不要在同一台机器上同时用 EXE 与 MSI 安装；切换形态先卸载其中一种。
- 域环境批量推送请先小范围验证 8.1 的版本比较规则，避免误判“同版本不升级”。

### 8.4 本版行为变化对部署的影响
- **置顶策略**：白板、讲台、AI 不再常驻置顶。机房若依赖“白板永远在最前”，需要接受窗口可被其他程序遮挡；时钟/倒计时仍始终置顶。
- **讲台照片默认不落盘**：默认不在磁盘留下照片。需要跨会话保留时，在「设置 → 展台」打开保存并设置保留天数（默认 1 天，1–30）；批量部署可预置 settings.json 中 Podium.SaveAlbumToDisk=true 与 Podium.AlbumRetentionDays。
- **设置界面 7 → 10 页签**：新增「展台」「更新」页；依赖设置窗口坐标或页签序号的自动化脚本需更新。
- 文件格式、数据目录、卸载保留策略、.hswb 关联均无变化。

### 8.5 升级后检查
1. 帮助/关于显示 1.2.6.1。
2. 打开一份旧 .hswb 确认可正常显示与保存。
3. .hswb 双击仍能打开（关联未丢）。
4. 讲台：缩放按钮可用；拍照后相册可打开且点空白不关闭；最小化/退出在底栏最右。
5. 「设置」应有 10 个页签，含「展台」「更新」。

## 9. v1.2.6 升级部署（历史，1.2.5 → 1.2.6；1.0.0–1.2.5 也可直接升至 1.2.6）

1.2.6 与 1.2.5/1.2.4/1.2.3/1.2.2/1.2.1/1.2.0/1.1.3/1.1.2/1.1.1/1.1.0/1.0.0 使用同一数据目录（%LOCALAPPDATA%\HoneySky White Board\）、同一 MSI UpgradeCode 与同一 Inno AppId，升级不需要迁移数据或改设置；.hswb 保持向后兼容（1.2.6 为 BrushTip 追加直线笔/水彩/粉笔三种新笔型，旧版本读取按默认笔型渲染；格式版本号以阶段 B 实测为准）。

### 9.1 EXE（Inno Setup）就地升级

```bat
rem 直接运行 1.2.6 安装包覆盖安装（可覆盖 1.2.5 及更早版本，无需先卸载）
HoneySkyWhiteBoard-1.2.6-win-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /LOG="%TEMP%\hswb-upgrade.log"
```

- 安装器按相同 AppId 识别旧版本并覆盖程序文件；用户数据目录不在安装目录内，升级不会删除文档、设置与缓存。
- 升级完成后在「⋯ → 关于」应显示 1.2.6；旧 .hswb 可直接打开（旧笔型笔迹按原样渲染）。
- 回滚：卸载 1.2.6 时保留用户数据，再安装 1.2.5 包即可（1.2.5 三产物仍在 dist）；更早版本的回滚包与 SHA-256 见 dist/checksums 下的对应清单。

### 9.2 MSI（WiX）MajorUpgrade

```bat
rem 直接安装 1.2.6 MSI，MajorUpgrade 自动移除旧版本（1.2.5 及更早）的 ProductCode 后再安装新版本
msiexec /i "HoneySkyWhiteBoard-1.2.6-win-x64.msi" /qn /norestart ALLUSERS=1 /l*v "%TEMP%\hswb-msi-upgrade.log"
```

- 升级依赖 UpgradeCode {B7D41E2A-9C33-4F6B-8E21-5A0C3D9F6B14} 保持不变；1.2.6 使用新 ProductCode {D523D5E7-D8BB-44A1-83F4-C1F5EF4FFD6B}（1.2.5 为 {704AC41A-C287-489D-BE30-370BFF254D7F}，1.2.4 为 {E2E6D6F3-0D8B-40BA-BA9F-6D3A0907DF55}，1.2.3 为 {727F958D-E390-40BA-9EA7-0699F9946EC8}，1.2.2 为 {2E82CA0C-675C-44C7-8914-AD06BE0954A8}，1.2.1 为 {3F3B8A2E-5C9D-4E52-9C3A-0B7D6E1F9A24}，1.2.0 为 {76D23280-8FDB-4872-A676-FB35AFBDC8FE}）。
- 不要把不同版本或不同封装形态交叉安装（例如 EXE 装旧版、MSI 装新版会留下两套卸载信息）。
- MSI 会阻止降级（1.2.6 已安装时再装更早版本会提示并回滚）；确需回滚先卸载 1.2.6（保留数据）再安装目标版本。

### 9.3 v1.2.6 新增行为对部署的影响

- **AI 讲台影像参数与相册**：采集/显示分辨率、色温、饱和度、对比度、亮度与缩放均为本地设置，保存在 settings.json 的 Podium 节点，不联网；讲台相册默认落盘到 %LOCALAPPDATA%\HoneySky White Board\Cache\PodiumAlbum（最多 24 张，可在设置调整），卸载清理选项按 Cache 子目录处理，默认卸载仍保留。
- **书写性能与笔画算法**：新增「设置 → 常规 → 笔画算法」（自动 / 流畅优先 / 平衡 / 画质优先）与低配模式开关。机房一体机若帧率不足，建议统一设为「流畅优先」或启用低配模式；这两项只影响渲染与动画，不改变文档内容。
- **新增三种笔尖**：直线笔、水彩、粉笔。旧版本（1.2.5 及更早）打开含新笔型的 .hswb 时按默认笔型渲染，不报错但观感不同；如机构混用新旧版本，建议统一升级。
- **PPT 切页**：同一文档内翻页复用动画解码并预热相邻页，低配机器动画帧率降为 10–12 FPS；不影响导入与保存。
- **时钟/倒计时独立**：时钟窗口不再附属于主窗口，主窗最小化/失焦时仍可置顶显示；关闭主窗会一并关闭时钟进程。
- **关于页头像联网**：打开关于页可能请求 api.bilibili.com 获取作者头像（失败自动回退内置图标），这是 1.2.6 新增的唯一后台网络请求；完全禁网环境会自动回退，不影响其他功能。
- **更新源可选**：更新弹窗与关于页新增更新源选择（自动 / GitHub 官方 / gh-proxy.com / ghproxy.net）。若机构只允许特定出口，请统一选择「GitHub 官方」，避免走第三方镜像；自动模式在 GitHub 不可达时会按顺序尝试镜像。
- **其他**：更新下载与断点续传、即刻更新、.hswb 关联、卸载数据保留策略与 1.2.5 一致；数据目录结构未变。

### 9.4 v1.2.5 新增行为对部署的影响（历史）

- **PPT / PPTX 导入依赖本机 PowerPoint**：导入 .ppt/.pptx 时程序调用本机 Microsoft PowerPoint COM 导出 PDF。机房如需该功能，请确认已安装桌面版 Office PowerPoint；未安装时导入会给出中文提示，其余功能不受影响。纯 WPS 环境未验证。
- **Word 导入改为懒加载**：导入后按访问页生成位图并缓存到 Cache\import\ 下。首次翻到未渲染页可能短暂显示渲染中，属预期；磁盘占用随访问页数增长，可在「设置 → 关于 → 清除缓存」清理（只清 Cache 与 Thumbnails，不动文档与设置）。
- **Word 阅读模式**：阅读控制条由主窗口接入，导入 Word 页面后可切换按页/按宽度适配、字号 A−/A+ 与三档行距；只影响显示，不修改原文档。
- **启动选项变化**：启动页不再有「即刻启动」与「以后不要再显示启动界面」，改为「设置 → 常规 → 启动时立即进入主界面」与「启动时显示动画」。机房统一跳过启动动画可关闭「启动时显示动画」；命令行 --no-splash 仍生效。
- **显示大小设置**：「设置 → 常规」新增左上角水印大小 0.6–1.6 与右下角操作条大小 0.7–1.5，默认 1.0；还原卡环境可把这些值写入 settings.json 后统一分发。
- **对象锁定与右键菜单**：均为本地交互，不写注册表、不联网；锁定状态随 .hswb 保存（旧版本打开忽略该标记）。
- **其他**：更新下载、即刻更新、.hswb 关联、卸载数据保留策略与 1.2.4 一致。

### 9.5 v1.2.4 新增行为对部署的影响（历史）

- **自动下载更新包**：程序发现新版本后会在后台把对应安装包（EXE 用户下 setup.exe，MSI 用户下 .msi）下载到 %LOCALAPPDATA%\HoneySky White Board\Updates\v<版本>\，同目录保留 .meta.json 下载记录；支持镜像回退与 Range 续传，下载完成用同一 Release 的 SHA256SUMS.txt 校验，校验失败会删除文件且不会运行。
- **磁盘与带宽**：单个安装包约 74–90 MB。机房/还原卡环境请预留磁盘空间；完全禁网环境检查更新会静默跳过，不会报错打扰。
- **即刻更新**：下载完成后用户可一键安装，程序会正常关闭（未保存文档仍有保存提示），由 .cmd 启动器静默运行安装包并在完成后重新打开原程序；安装期间不要断电，中断时手动运行 Updates 目录中的安装包即可。
- **关于页不弹窗**：设置窗口停在「关于」页时发现新版本不弹更新窗口，只在该页显示进度；不影响静默安装与批量部署。
- **启动动画 3 秒可调**：「设置 → 常规 → 启动动画时长」可设 3–15 秒；机房可用 `--no-splash` 参数跳过启动页（在快捷方式目标后追加）。
- **卸载清理**：Updates 目录位于用户数据根下，卸载默认保留；勾选「同时删除个人文档、设置和缓存」时按固定子目录清理（如阶段 B 实测发现未覆盖 Updates，需在发布报告中如实记录）。

### 9.6 v1.2.3 行为变化对部署的影响（历史）

- **触控书写与掌擦**：触摸输入并入统一手势通道，掌压自动橡皮由「设置 → 书写 → 手掌误触自动橡皮」控制（默认开启）。教室一体机建议保持开启；若教师习惯用手掌支撑书写且出现误擦，可关闭该开关。
- **Dock 尺寸**：默认放大到 1.10；「设置 → 工具栏 → Dock 大小」可在 0.85–1.40 调整。小屏/投影分辨率较低时可调小，窄窗口会自动等比回退避免遮挡画布按钮。
- **导入翻页**：PDF/Word 背景改为后台渲染，首次翻到未缓存页可能短暂显示「正在渲染背景」；这是预期行为，不影响已保存文档。
- **讲台旋转**：旋转仅影响本次讲台会话的画面与输出，不改变白板页面与已保存内容；重启讲台回到 0°。
- **官网许可文案**：官网许可区为「不开源，正式版可免费使用」；机构采购仍以 EULA 与 LICENSE-PROPRIETARY.txt 为准。
- v1.2.2 引入的全屏浮窗置顶、启动默认不提示恢复、清除缓存、更新检查顺序等行为继续适用。

### 9.7 升级后检查

1. 「⋯ → 关于」显示 1.2.6，数据目录正确。
2. 打开一份 1.0.0 或 1.1.x 保存的 .hswb，内容正常（旧文档按钢笔笔尖兼容读取）。
3. 资源管理器双击 .hswb 仍能打开（文件关联未被破坏）。
4. 旧用户数据与设置保留；静默卸载 1.2.6 后数据仍在；核对 Updates、Cache\PodiumAlbum 目录按策略保留或清理。
5. 「⋯ → 检查更新」在已是最新时应提示无新版本；发现新版时应显示下载进度与速度。
6. 启动页只保留图标/名称/版本/进度；「设置 → 常规」中「启动时立即进入主界面」「启动时显示动画」与启动动画时长（3–15 秒）均生效。
7. 「设置 → 常规」中「笔画算法」四档可切换并即时生效；讲台影像参数可调且重启讲台后保留；更新弹窗/关于页的「更新源」四选项可切换并保存。

## 10. 批量部署检查清单

1. 在代表性机型（含触控一体机）上做一次冒烟：启动 → 书写 → 保存 `.hswb` → 关闭 → 双击文档重新打开。
2. 确认卸载后 `%LOCALAPPDATA%\HoneySky White Board` 仍在（数据保留策略生效）。
3. 确认杀软/EDR 未隔离安装目录下的自包含 exe/dll（首次分发建议加白名单）。
4. 若教室无外网：确认时钟回退提示可接受、AI 功能保持未配置状态。
5. 若使用触控笔：在目标机型上验证压感与手掌误触抑制是否符合预期（压感可在设置中关闭）。
6. 记录发布包 SHA-256（`dist/checksums/SHA256SUMS.txt`）归档，便于后续审计与升级比对。

## 11. 常见部署问题

| 现象 | 原因与处理 |
| --- | --- |
| 安装被 SmartScreen 拦截 | 未签名。核验 SHA-256 后「仍要运行」，或由 IT 预先放行哈希 |
| `1603` 安装失败 | 常见为文件被占用（先退出旧版本）、权限不足、或磁盘空间不足；查看 `/l*v` 日志定位 |
| 静默安装后无快捷方式 | 静默安装仍会创建开始菜单项；桌面图标取决于安装选项/策略（见安装脚本 Tasks） |
| 用户数据找不到 | 安装版在 `%LOCALAPPDATA%`（不是安装目录）；绿色版在程序目录 `Data\`；可用 `HONEYSKY_DATA_DIR` 覆盖 |
| 双击 `.hswb` 打不开 | 文件关联被其他软件占用，或策略禁止；改用程序内「文件 → 打开」 |
| AI 一直不可用 | 未配置服务（BYOK，软件不预置任何服务），需在设置 → AI 服务中填写 BaseUrl/Model/Key |

技术支持需要收集的信息：版本号（设置 → 关于）、`Logs\app.log`、复现步骤、是否需要网络授时/AI。
