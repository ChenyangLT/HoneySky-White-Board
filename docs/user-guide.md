# HoneySky White Board 用户手册

适用版本：1.2.2 ｜ 平台：Windows 10 1809 及以上 / Windows 11（仅 x64）｜ 更新日期：2026-10-31

本手册面向日常使用本软件的老师、讲师与会议记录者，按“安装 → 界面 → 书写 → 教具 → 文档 → 设置 → AI → 故障排查”的顺序说明每一项功能怎么用。安装包形态、数据目录结构、从源码构建等内容见仓库根目录的 README.md。

---

## 1. 安装与首次启动

三种安装形态任选其一，**不要同时安装 EXE 与 MSI**：

| 形态 | 文件 | 适用场景 |
| --- | --- | --- |
| EXE 安装包（Inno Setup） | `dist/installer/HoneySkyWhiteBoard-1.2.2-win-x64-setup.exe` | 个人电脑，双击向导安装 |
| MSI 安装包（WiX） | `dist/installer/HoneySkyWhiteBoard-1.2.2-win-x64.msi` | 学校/企业批量部署 |
| 绿色便携版 | `dist/portable/HoneySkyWhiteBoard-1.2.2-win-x64-portable.zip` | U 盘、临时机器、免安装 |

**首次启动**：程序会以最大化窗口打开（因为没有历史窗口位置），并自动新建一个空白文档、一页空白页。之后每次启动会恢复上次的窗口大小/位置与最大化状态。

**关于「未知发布者」提示**：1.2.2 未做代码签名，SmartScreen 可能提示“Windows 已保护你的电脑”。请先核对 `dist/checksums/SHA256SUMS.txt` 中的 SHA-256，确认一致后点“更多信息 → 仍要运行”。

## 2. 界面导览

> **v1.1 起界面改版**：主窗口改为无边框全屏启动，底部是常驻控制栏，左侧页面栏默认自动隐藏，另有可拖动的浮动工具条，详见文末 **第 16 节**。下面先保留 v1.0 的四区说明（顶栏菜单、快捷键、设置入口仍然适用）。

主窗口分四个区域：

1. **顶部工具栏**：左侧是品牌按钮（点击打开主菜单），中间是书写与教具按钮，右侧是缩放、页码、更多工具与设置入口。
2. **左侧页面栏**：显示每一页的缩略图与页序号，顶部「页面 +」按钮新建页面；点击缩略图切换页面。
3. **中央画布**：无限画布，承载所有笔迹、图形与图片对象。
4. **底部状态栏**：左侧显示当前操作提示与工具提示，右侧显示文档名、页码与缩放比例；文件有未保存修改时右下角会出现「未保存」标记。

**主菜单**（点击左上角品牌按钮）：文件、编辑、视图、工具、帮助、退出。菜单项右侧显示当前生效的快捷键，快捷键被改过之后菜单也会同步更新。

窗口底部状态栏与工具栏中的提示文案，是判断“当前工具是什么、刚发生了什么”的最快途径。

## 3. 书写与擦除

> **v1.1 起**：点击底栏的笔、荧光笔或橡皮会在工具旁弹出二级面板，可直接选颜色、粗细与笔尖（钢笔/马克笔/毛笔），见 **16.2**。以下设置项仍然生效，可作为默认值。

### 3.1 画笔（钢笔）

- 工具栏点「画笔」（快捷键 `P`）。
- 在画布上按下并拖动即可书写；鼠标、触摸、触控笔都可用。
- 触控笔书写时默认按压感调整笔迹粗细；压感可在 **设置 → 书写 → 启用压感** 关闭（关闭后笔迹等宽）。
- 笔迹颜色与粗细在 **设置 → 书写** 中调整（默认 `#FF1F2329`、3.0 DIP）。
- 笔迹使用平滑曲线拟合，快速书写也不会变成一串圆点。

### 3.2 荧光笔

- 工具栏点「荧光笔」（快捷键 `H`）。
- 半透明高亮，**同一笔迹内部不会因叠加而加深**（起笔与回笔颜色一致），适合划重点。
- 默认颜色 `#66F2A33C`（30% 不透明橙）、宽度 18 DIP，可在设置中修改。

### 3.3 橡皮擦

工具栏点「橡皮擦」（快捷键 `E`）。支持两种模式，可在 **设置 → 书写 → 橡皮擦模式** 切换：

| 模式 | 行为 |
| --- | --- |
| 局部擦除（默认） | 按住拖动，按擦除圆形/胶囊形状**真实切割笔迹**（不是用白线盖住），可一次擦掉笔画的一部分 |
| 整笔擦除 | 碰到哪一笔就整条删除 |

- 擦除半径在 **设置 → 书写 → 橡皮擦半径** 中调整（4–64 DIP，默认 16）。
- **两种模式都支持撤销**：一次擦除动作（从按下到抬起）记为一条撤销记录。
- 长按/拖动时画布上会显示擦除范围预览。

### 3.4 撤销与重做

- 撤销：`Ctrl+Z` 或工具栏「撤销」；重做：`Ctrl+Y` / `Ctrl+Shift+Z` 或工具栏「重做」。
- 撤销栈覆盖书写、擦除、图形插入、对象删除、移动/缩放、页面增删等文档级操作。

## 4. 选择、移动与图形

### 4.1 套索选择

- 工具栏点「套索」（快捷键 `L`），在画布上圈出一个闭合区域，完全落在区域内的对象被选中。
- 按住 `Ctrl` 或 `Shift` 再圈选可**追加选择**。
- 选中后可直接拖动移动、拖动角柄缩放；`Delete` / `Backspace` 删除所选。

### 4.2 选择工具

- 工具栏点「选择」（快捷键 `V`），点击对象选中、拖动移动、拖角柄缩放。
- 空白处单击或按 `Esc` 取消选择。

### 4.3 图形工具

工具栏提供四种图形：直线、箭头、矩形、椭圆。

- 按下后拖动决定起点与终点，抬起即生成对象；生成的图形可被选择/移动/缩放/删除，也可被套索选中。
- 无触屏旋转手势时按自由角度绘制；按住 `Shift` 可约束为水平/垂直/等比（触摸设备上按住 Shift 需要外接键盘）。
- 图形描边颜色与线宽取自设置中的书写颜色/线宽（`ShapeStrokeColor` / `ShapeStrokeWidth`）。

## 5. 缩放、平移与翻页

| 操作 | 方式 |
| --- | --- |
| 缩放 | 鼠标滚轮（以指针位置为中心）；工具栏 `+` / `−`；`Ctrl+OemPlus` / `Ctrl+OemMinus` |
| 适应窗口 | 工具栏「适应窗口」按钮或 `Ctrl+0`（把全部内容缩放到可见范围） |
| 100% | 工具栏右侧点击百分比文本恢复 100%（`ResetView`） |
| 平移 | 触摸：单指拖动（手指绘制关闭时）/双指拖动；鼠标：工具栏「选择」工具下拖动画布空白处 |
| 双指缩放 | 触摸双指捏合，以两指中心缩放 |
| 翻页 | 工具栏 `‹` `›`、`PageUp` / `PageDown`，或点击左侧页面缩略图 |

状态栏右侧实时显示当前缩放比例（如 `100%`）。

## 6. 屏幕直尺与圆规

### 6.1 直尺

工具栏点「直尺」（快捷键 `R`），画布中央出现一把半透明直尺：

- **拖动尺身**移动直尺；**拖动两端手柄 A/B** 旋转与改变长度；滚轮调整长度；`Shift`+滚轮按 15° 步进旋转。
 - 状态栏会给出操作提示（“拖动两端旋转/调长 · 拖动尺身移动 · 滚轮调长 · Shift+滚轮旋转 · 双击生成线段”）。
- 直尺上显示厘米/毫米刻度与 A→B 的距离读数：`≈ 7.94 cm`。
- **未校准**时读数标注「未校准（估算）·按 C 校准」：屏幕 DPI 与实际物理尺寸存在偏差，按 `C` 进入校准流程，用屏幕上量得的已知长度换算，校准后读数与刻度按真实厘米显示。
- **双击直尺**把当前 A→B 线段写入画布，成为可编辑的对象。

### 6.2 圆规

工具栏点「圆规」（快捷键 `C`）：

- 蓝色虚线圆 + 圆心十字 + 半径手柄；拖动圆心移动、拖动圆周旋转、滚轮调半径、`Shift`+滚轮按角度步进。
- 圆旁读数：`R ≈ 4.23 cm（估算）`、`周长 ≈ 26.60 cm`、角度。
- 下方浮出半径输入面板：输入数值（厘米）后点「确认」，或在画布上**双击圆**，把圆写入画布成为可编辑对象。
- 半径同样受 DPI 校准影响；未校准时标注“估算”。

两次使用教具前请确认 DPI 校准状态：投影/一体机、系统缩放 125%/150% 时未校准的读数会与真实物理尺寸有偏差。

## 7. 时钟与倒计时

工具栏点「时钟」（`K`）/「倒计时」（`Shift+K`），在画布右上角浮出两个卡片（可再次点击关闭）：

- **时钟**：大字号时:分:秒 + 日期与星期；绿色圆点表示时间来源（`网络授时·已校准（SNTP ntp.aliyun.com）` 或回退系统时间），右侧「立即校准」按钮手动重新校时。网络授时失败时自动回退系统时间并标注，**不会修改系统时间**。
- **倒计时**：预设 1/5/10/25 分钟，或输入自定义分钟数后「设置」；「开始/暂停/继续/重置」控制流程；时间到时弹提示并在状态栏提示「倒计时结束」。

## 8. 页面与背景

- **新建页面**：页面栏顶部「页面 +」；新页面沿用当前背景色。
- **切换页面**：点击缩略图，或 `PageUp` / `PageDown`、工具栏 `‹` `›`。
- **删除页面**：主菜单 → 文件/编辑中的删除页命令；只剩一页时会提示“至少保留一页”。
- **页面缩略图**：默认关闭（`设置 → 常规 → 显示页面缩略图`）。开启后页面栏显示每页的实时缩略图（书写、擦除、移动后自动刷新）。
- **页面栏显示/隐藏**：`Ctrl+B` 或 设置 → 常规 → 显示页面栏。
- **背景颜色**：工具栏「背景颜色」按钮或主菜单，弹出颜色选择器，选中后应用到当前页；支持十六进制值与预设色板。

## 9. 文档：新建、打开、保存、导出

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建 | `Ctrl+N` | 新建空白文档（当前文档有改动会先询问是否保存） |
| 打开 | `Ctrl+O` | 打开 `.hswb` 文档；也可直接双击文件或把路径作为启动参数传入 |
| 保存 | `Ctrl+S` | 首次保存弹出“保存白板文档”对话框选择位置 |
| 另存为 | `Ctrl+Shift+S` | 指定新路径保存 |
| 导出当前视图 | `Ctrl+Shift+E` | 导出为 PNG 图片（所见即所得） |

- **文档格式 `.hswb`**：ZIP 容器，内含 `manifest.json`、`document.msgpack.gz`、图片资源与缩略图，带 SHA-256 完整性校验与版本号，规范见 `docs/file-format/hswb-format.md`。
- **自动保存**：默认每 30 秒（`设置 → 常规 → 自动保存间隔` 可改 5–3600 秒）以及在切页时保存；未保存到文件的文档会写入恢复数据。
- **异常恢复**：程序异常退出后，下次启动会提示恢复上次未保存的内容（数据位于数据目录 `Recovery`）。
- **关闭提醒**：关闭窗口时若存在未保存修改，会询问“保存 / 不保存 / 取消”。

## 10. 工具栏自定义

进入 **设置 → 工具栏**：

- 列表按当前显示顺序排列，每一行可：**勾选/取消显示**、**上移/下移**（▲▼ 调整顺序）。
- 「固定」的项目在窗口变窄时不会被收进「更多」菜单。
- 窗口宽度不足时，靠后的按钮自动收进工具栏右侧的「⋯ 更多工具」菜单；在设置里调整顺序即可控制谁先被收起。
- 「恢复默认工具栏」把显示项与顺序还原为出厂配置。

可自定义的按钮：画笔、荧光笔、橡皮擦、套索、选择、直线、箭头、矩形、椭圆、直尺、圆规、时钟、倒计时、AI 讲台、撤销、重做、背景颜色、放大、缩小、适应窗口、页面栏开关、上一页、下一页、设置、更多。

## 12. 设置项速查

设置窗口共 7 个页签：

1. **常规**：主题（浅色/深色/跟随系统）、启用自动保存、自动保存间隔（秒）、显示页面栏、显示页面缩略图、启动时恢复上次打开的文档。深色主题下主窗口、设置窗口、AI 悬浮窗与颜色选择对话框的原生标题栏都会同步变为深色（系统文件对话框与系统消息框由 Windows 绘制，仍为系统配色）。
2. **书写**：笔迹颜色与粗细、荧光笔颜色与粗细、启用压感、允许手指绘制、橡皮擦模式（局部/整笔）、橡皮擦半径。
3. **工具栏**：显示/隐藏、排序、固定、恢复默认（见第 10 节）。
4. **快捷键**：逐个动作绑定、冲突检测、恢复默认（见第 11 节）。
5. **动画**：启用动画、动效强度（完整/减弱/极简）、跟随系统“减少动态效果”设置。
6. **AI 服务**：API 地址、模型名称、API Key、上下文 token 上限、多轮对话与保留轮数、DeepSeek 余额查询开关、分段超时（连接/首 token/流式空闲/总时长，见 13.7）、测试连接。
7. **关于**：版本号、数据目录、开源许可与第三方声明入口、项目链接、打开数据目录。

底部「恢复所有默认设置」会**重置全部设置**（含工具栏与快捷键），需要二次确认。

## 13. 问 AI（AI 助手浮窗，需自备 OpenAI 兼容服务）

底栏「问 AI」或顶栏菜单「问 AI」打开 AI 助手浮窗（v1.0 中名为「AI 展台」），可以边板书边提问。软件**不预置任何 AI 服务与密钥**，未配置时不会发起任何网络请求。需要带摄像头画面讲解时请使用 13.5 的 AI 讲台；`Q` 现在打开的是 AI 讲台，不再打开本浮窗。

### 13.1 配置（BYOK，自带密钥）

1. 打开 **设置 → AI 服务**（AI 窗口右上角齿轮、或未配置时提示条上的「去配置」按钮可直接跳到该页）。
2. 填写：
   - **API 地址（BaseUrl）**：例如 `https://api.deepseek.com` 或任意 OpenAI 兼容网关（需支持多模态图片输入）。
   - **模型名称（Model）**：默认模型已改为 `deepseek-flash`（DeepSeek 官方，支持图片输入）；纯文本场景可用 `deepseek-v4-pro`（收到图片会被服务端忽略，不报错）。其他 OpenAI 兼容网关请填其上支持视觉的模型名，例如 `gpt-4o-mini`。
   - **API Key**：保存后由 Windows DPAPI 加密写入数据目录 `Settings\api-key.dat`，日志与界面不回显明文。
   - 可选：上下文 token 上限（默认 32768）、多轮对话与保留轮数（默认 8）、DeepSeek 余额查询开关、分段超时（连接 15 秒 / 首 token 60 秒 / 流式空闲 60 秒 / 总时长默认不限，见 13.7）。
3. 保存后可点「测试连接」（发送 `max_tokens=8` 的最小请求）确认地址、模型与 Key 可用，再开始提问。

### 13.2 提问流程

1. 选择图片（可选，最多一张）：**摄像头拍照** / **本地图片** / **剪贴板** / **页面截图**（截取当前画布视图）。
   - 图片自动预处理：最长边压缩到 2048 像素以内、体积不超过 2MB（JPEG 85 / PNG），界面显示压缩前后的尺寸与体积。
2. 在输入框输入问题（支持 `$E=mc^2$` 形式的 LaTeX 与 Markdown 提示）。
3. 点「发送」：回答以**流式**方式逐字显示，渲染 Markdown 标题/列表/表格/代码块与 LaTeX 公式；「停止」可随时中断。
4. 多轮对话默认开启：每次请求携带系统提示词、当前图片与**最近 8 轮**历史；按 token 估算预留 20% 上下文，超出时会真实统计并提示“已省略 N 轮”。
5. 底部左侧显示余额（仅当服务为 DeepSeek 官方接口且开启查询时；失败显示“不可用”），右侧显示当前历史轮数。

### 13.3 窗口行为

- 非模态悬浮窗：可拖动标题栏移动、拖动边缘缩放，位置与大小会被记住，下次启动若上次是打开状态则自动恢复。
- 关闭按钮只关闭窗口（不退出程序），主窗口关闭时 AI 窗口一起关闭。

### 13.4 隐私与费用

- 只有你点「发送」时才会把「所选图片 + 输入文字 + 最近对话历史」发送给你配置的服务商。
- 调用产生的费用、数据留存与合规责任由该服务商条款约束，本软件不做中转、不收集内容。
- API Key 只保存在本机当前用户的数据目录，使用 DPAPI 加密（离开该用户账户无法解密）。

### 13.5 AI 讲台（v1.1 新增）

底栏工具组「AI 讲台」或按 `Q` 打开全屏讲台窗口，用于对着实物/纸张讲解：

1. 摄像头画面铺满窗口；无摄像头或设备被占用时显示「未检测到摄像头」与「重试」按钮，不会崩溃。
2. 「批注」可在画面上直接书写，笔迹与画笔颜色/粗细联动；「拍照入白板」把当前画面连同批注一起插入白板当前页。

4. 退出时若有未保存批注，会询问「保存到白板 / 丢弃」；选择保存即把批注与画面加入白板。

### 13.6 问 AI 浮条（v1.1 新增）

- 底栏「问AI」打开浮条，只发送你输入的问题与最近对话历史，**不会自动附带白板截图**；需要画面信息时请使用 AI 讲台的「问 AI」，或在本浮窗手动选图。
- 流式回答、停止、多轮历史与错误提示与第 13 节的 AI 助手浮窗一致。

### 13.7 分段超时与错误重试（v1.1 新增）

| 阶段 | 默认超时 | 说明 |
| --- | --- | --- |
| 建立连接 | 15 秒 | 包含 DNS/TLS/代理握手 |
| 等待首个 token | 60 秒 | 服务商排队较慢时可适当增大 |
| 流式空闲 | 60 秒 | 两个数据块之间的最长等待 |
| 总时长 | 不限（0） | 长回答不会被总超时截断 |

- 在 **设置 → AI 服务 → 分段超时** 中修改；旧的单次「请求超时」只用于余额查询。
- 超时/HTTP 错误会在回答区域显示阶段、状态码与可重试按钮，日志只记录阶段、耗时、状态码、消息条数与字符数，不记录 API Key 与图片内容。
- 若服务返回 400 且提示 image/vision 相关，通常是该模型不支持图片输入，改用纯文本提问或更换支持视觉的模型。

## 14. 故障排查

| 现象 | 处理 |
| --- | --- |
| 双击安装包提示“未知发布者” | 未做代码签名，核对 SHA-256 后选择“仍要运行”（见第 1 节） |
| 启动后画布空白、无提示 | 检查数据目录是否可写（便携版放在 Program Files 下会不可写并自动回退），日志见 `Logs\app.log` |
| 摄像头拍照提示无设备 | 设备管理器确认摄像头存在且未被其他程序独占；无物理摄像头的机器无法使用该功能 |
| 时钟显示“系统时间（未校准）” | 网络不可达或被防火墙拦截 NTP/HTTPS，可点「立即校准」重试；不影响其他功能 |
| AI 提示 401/403 | API Key 错误或无该模型权限，重新在设置中填写 |
| AI 提示 429/超时 | 服务商限流或网络慢，稍后重试，或在设置 → AI 服务中调整分段超时（见 13.7） |
| 直尺/圆规读数与实物不符 | 系统缩放非 100% 时需先按 `C` 做 DPI 校准 |
| 笔迹在别的电脑上粗细不同 | 笔迹记录的是 DIP 坐标，缩放比例与屏幕 DPI 会影响观感，属预期行为 |

**日志位置**：数据目录 `Logs\app.log`（默认 `%LOCALAPPDATA%\HoneySky White Board\Logs\app.log`）；日志不含 API Key。

**数据目录**：安装版 `%LOCALAPPDATA%\HoneySky White Board\`；绿色版 `程序目录\Data\`；可用环境变量 `HONEYSKY_DATA_DIR` 覆盖。

### 16.6 常见疑问

- 「⋯ → 导入文件…」或 Dock「导入」面板：支持 PDF、Word（.docx）、PNG/JPG/BMP。

- Word：提取标题、加粗、斜体、下划线、列表、表格与对齐，用内置排版渲染；面板里可实时调整字号（10–28）与行距（1.0–2.5）。
- 图片：直接作为页面背景铺入。

- 启动后约 3 秒静默检查一次新版本（最多等 5 秒，失败自动切换镜像，全部失败则安静跳过）。

- 也可随时在「⋯ → 检查更新…」手动检查，会显示检查中/结果提示。
- 更新检查只访问公开发布接口获取版本号与下载链接，不上传任何本地数据；内网无法访问时不影响正常使用。

### 17.7 讲台拍照与对比

- 在 AI 讲台里点相机按钮拍照：照片缓存到本次讲台会话（最多 12 张，内存保存），画面切到「图片讲解模式」，底部出现照片缩略图条，可点击切换。
- 相机按钮右上角 `^` 打开拍照面板：
  - **对比图片**：在「仅原图 / 仅批注 / 叠加 50%」之间切换，或按住按钮临时只看原图；
  - **保存图片**：把当前照片与批注合成一张 PNG，默认保存到「文档」目录，文件名形如 `讲台批注-20261031-153000.png`；
  - **删除当前照片**。
- 每张照片的批注相互独立，切回时保留；退出讲台仍会询问是否把当前照片与批注保存为白板新页。

### 17.8 AI 回答字号

- AI 回答区底部新增字号工具条：`A−` / 滑块（12–22）/ `A+` / 当前百分比；默认 14.5。
- 调整后立即生效，并写入设置；下次打开 AI 窗口沿用上次字号。

### 17.10 常见疑问

- **找不到设置入口？** v1.2.0 起设置只在 Dock 最右侧「⋯」菜单里。

- **更新提示一直没出现？** 无网络或接口不可达时会静默跳过；可手动「⋯ → 检查更新…」查看原因。

- 全屏与窗口态下按钮图标与悬停提示会随状态变化，不影响 100% / 适应页面等既有按钮。

### 18.3 缩略图条显示数量可设
- 左下页面缩略图条只显示设定数量的页面，多余页面可滚动查看，避免占用画布。
- 具体数量在设置中调整，修改后立即生效并记住。

### 18.4 橡皮与形状工具切换
- 修复：从橡皮切回形状（或反向）时不再意外取消当前工具，选中态与实际工具保持一致。

### 18.5 关于页与水印
- 「设置 → 关于」的品牌动画由「扫两次后静止」改为默认每 5 秒循环播放，间隔可在「设置 → 动画 → 品牌字闪光间隔」中调整为 2–30 秒。
- 全屏左上角品牌水印的位置与透明度调整，不遮挡书写与点击；窗口态下不显示。

### 18.6 从 1.2.0 升级

## 19. v1.2.2 更新（全屏浮窗置顶、清除缓存等）

> 本节按 v1.2.2 任务书与 2026-10-31 真机验证记录编写，界面细节以实际版本为准。

### 19.1 全屏下的浮窗置顶
- 全屏白板中打开「问 AI」「设置」「二级面板」等浮窗时，浮窗始终显示在白板之上，不会被画布或工具栏盖住。
- 退出全屏（Esc / F11 / 顶栏还原）后浮窗恢复普通窗口层级，不再强制置顶。
- 同时打开多个浮窗时，后打开的在最上层；关闭浮窗不影响其它窗口。

### 19.2 关于页 GitHub 直达
- 「设置 → 关于」新增 GitHub 仓库链接，点击后用系统默认浏览器打开项目主页（https://github.com/ChenyangLT/HoneySky-White-Board）。
- 无外网时链接仍可点击，浏览器会提示无法访问；不影响软件其它功能。

### 19.3 更新检查顺序
- 启动后仍会静默检查一次更新，顺序为：先访问 GitHub Releases 接口，失败后自动切换镜像源，镜像也失败则静默跳过，不打扰使用。
- 「⋯ → 检查更新」手动检查走同一顺序；内网/无外网环境保持默认即可，不会自动下载或安装。

### 19.4 启动不再默认提示恢复
- 启动时默认不再弹出「上次未保存的文件」恢复提示，直接进入白板。
- 需要恢复旧草稿时，可在「设置 → 常规」打开「启动时提示恢复未保存文件」；Recovery 目录中的草稿不会被自动删除，仍可手动打开。
- 该开关默认关闭，从 1.2.1 升级后也保持关闭。

### 19.5 清除缓存
- 「设置 → 关于」新增「清除缓存」按钮：确认后清理 Cache（导入缓存、缩略图等）与 Thumbnails 目录，完成后提示释放的字节数。
- 只清理缓存，不删除个人文档、设置、Recovery 草稿与日志；清理后首次打开导入的 PDF/Word 页面会重新渲染，稍慢属正常。

### 19.6 从 1.2.1 升级
- 直接运行 1.2.2 安装包覆盖安装（EXE 与 MSI 均可，无需先卸载）；文档、设置与缓存全部保留。
- MSI 使用同一 UpgradeCode 通过 MajorUpgrade 自动替换旧版本；升级后「设置 → 关于」应显示 1.2.2。
- 绿色版用户可直接用 1.2.2 的 zip 覆盖原目录（保留 Data 目录），portable.marker 与数据不受影响。
