功能

为老师，也为每一个把想法画出来的人。

从一支笔开始，到 AI 讲台答题。每一处细节都为「讲清楚一件事」而设计。

书写与笔触

像笔一样，像纸一样。

笔迹平滑与压感整笔重绘，250 Hz 采样下依然跟手。橡皮可整笔擦除，也可局部擦除；手指绘画默认关闭，避免误触。

  • 压感笔迹与实时光滑
  • 局部擦除 / 整笔擦除两种橡皮
  • 自动化笔迹，随手写就有体面

时间工具新

时钟与倒计时，搬到独立窗口。

时钟与倒计时是始终置顶的独立窗口，不遮挡板书：字号与背景透明度都能调，字号放大后文字依然清晰。

AI 讲台与助手

讲解不再是一个人对着黑板。

把题目交给 AI 讲台：拍下纸张、贴入图片，AI 在白板上边写边讲，支持 LaTeX 公式。日常答疑则交给角落里的 AI 助手浮窗。

AI 功能为可选能力，使用你自己的 OpenAI 兼容接口与 API Key；密钥经 Windows DPAPI 加密保存在本机。

页面与工具

多页白板，工具栏按你的习惯排。

一节课不止一页：缩略图栏随手翻页，缩放与适应窗口一键到位。工具栏里的工具能显示、固定、上下调序，快捷键也可改。

还有这些

用得越久，越觉得顺手。

半透明荧光笔

粉笔质感的高亮，叠在文字上不遮字，粗细可调。

直尺与圆规

屏幕上拉一把直尺，或画一个精确的圆，讲几何课很省事。

自动保存与恢复

定时自动保存，异常退出后下次启动可恢复上次的白板。

背景与导出

白板、纸张、深色背景随意换；一键导出高清图片。

快捷键

P 画笔、E 橡皮、K 时钟……常用操作都有快捷键。

克制的界面

浅色与深色主题，工具条与面板为课堂而不是为炫技而存在。

v1.2.4 新增新

更新自己下，启动你说了算。

这一版把「等」从更新和启动里拿掉了：检查到新版本就在后台静默下载，弹窗和「设置 → 关于」看到同一条进度；下载并校验完成后，关于页的「即刻更新」能直接安装；更新内容随时展开看，正停在关于页时不再弹窗打断。启动页默认至少停 3 秒，时长可调，也能「即刻启动」直接进。

更新包在后台自己下

检查到新版本后立刻在后台开始下载，不需要再确认；界面显示已下载/总大小、百分比与速度，进度至少每 200ms 刷新一次。支持断点续传，直连失败会自动换镜像源。

两个地方，同一条进度

更新弹窗和「设置 → 关于」里的软件更新卡片显示同一条下载：关掉弹窗下载不会停，重新打开弹窗或切到关于页，看到的就是当前进度。

下载完，在关于页点「即刻更新」

下载完成并通过 SHA-256 校验后，「即刻更新」才可点。确认后走正常的关闭流程（未保存文档的保存提示仍然保留），由安装包接管更新，装完重新打开白板。

更新内容能展开看

Release 说明在更新弹窗和关于页都能展开阅读，先看清这一版改了什么，再决定是现在更新还是稍后再说。

停在关于页时不弹窗

正在「设置 → 关于」看版本信息时，检查到新版本只在该页显示进度和更新内容，不会弹窗打断；离开关于页之后再按常规弹窗提示。

启动至少 3 秒，也能即刻启动

启动页默认至少停留 3 秒，可在「设置 → 常规」调到 3–15 秒。不想等就点「即刻启动」直接进主界面，旁边「以后直接启动」勾选后下次不再显示启动页。
