功能

为老师，也为每一个把想法画出来的人。

从一支笔开始，到 AI 讲台答题。每一处细节都为「讲清楚一件事」而设计。

书写与笔触

像笔一样，像纸一样。

笔迹平滑与压感整笔重绘，250 Hz 采样下依然跟手。橡皮可整笔擦除，也可局部擦除；手指绘画默认关闭，避免误触。

  • 压感笔迹与实时光滑
  • 局部擦除 / 整笔擦除两种橡皮
  • 自动化笔迹，随手写就有体面

时间工具新

时钟与倒计时，搬到独立窗口。

时钟与倒计时是始终置顶的独立窗口，不遮挡板书：字号与背景透明度都能调，字号放大后文字依然清晰。

AI 讲台与助手

讲解不再是一个人对着黑板。

把题目交给 AI 讲台：拍下纸张、贴入图片，AI 在白板上边写边讲，支持 LaTeX 公式。日常答疑则交给角落里的 AI 助手浮窗。

AI 功能为可选能力，使用你自己的 OpenAI 兼容接口与 API Key；密钥经 Windows DPAPI 加密保存在本机。

页面与工具

多页白板，工具栏按你的习惯排。

一节课不止一页：缩略图栏随手翻页，导入的文档有页码、滑条与目录，缩放与适应窗口一键到位。工具栏里的工具能显示、固定、上下调序，画布右键还能复制、剪切、粘贴与置顶置底。

v1.2.5 新增新

导进来的，直接能讲。

这一版把「导入」和「整理」做顺了：PDF / Word / PPT / 图片导入后自动铺满视口并带上黑色边框投影，PPT 能在软件里播放淡入、飞入、擦除，Word 有了整页阅读模式，导入文档有页码、滑条与目录；画布右键能复制、剪切、置顶、固定；低配电脑一键调顺，启动页更干净，图标换成蓝色带笔，关于页也不再出现 B 站入口。

导入即可铺满画布

PDF、Word、PPT、图片导入后默认铺满约 80% 视口，不糊在角落；导入内容自带黑色边框与投影，讲课时画面立得起来。

PPT / PPTX 也能直接讲

支持导入 PowerPoint；播放时软件自己渲染淡入、飞入、擦除等常用动画（动画信息依赖本机 PowerPoint 导出，未装 PowerPoint 的机器仍可翻页讲解）。

Word 有了阅读模式

导入的 Word 文档默认按整页显示，字号与行距都能调，长文档不再溢出画布，投影时学生看得清整页排版。

导入文档的翻页条

导入的 PDF / Word / PPT 有专属翻页条：当前页码、可拖的进度滑条与目录跳转，讲到哪里一目了然。

画布右键，一整套整理

右键即可复制、剪切、粘贴、复制一份、删除，还能置顶、置底与固定：板书叠得再多，也能把要讲的那一层拎到最上面。

掌压自动橡皮改为测试功能

手掌大面积接触屏幕时自动切换橡皮的行为改为「测试功能」，默认关闭。手写不再被误判打断，需要的人在设置里再打开。

低配电脑也能一键调顺

新增低配电脑一键推荐 / 恢复：针对 4 GB 内存与 60 Hz 屏幕，自动关闭动画、缩略图与预取，自动保存放宽到 60 秒，用完一键还原。

启动页更干净，图标换新

启动页只留品牌与进度，「即刻启动 / 以后直接显示」两个按钮移进设置；全站黄色 H 换成蓝色带笔图标，关于页也移除了 B 站入口。

v1.2.4 的后台静默下载、双处进度、下载完即刻更新、更新内容展开、启动最少 3 秒可调都还在。
