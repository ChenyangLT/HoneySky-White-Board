功能

像笔一样，像纸一样。

笔迹平滑与压感整笔重绘，250 Hz 采样下依然跟手。橡皮可整笔擦除，也可局部擦除；手指绘画默认关闭，避免误触。

时间工具新

AI 功能为可选能力，使用你自己的 OpenAI 兼容接口与 API Key；密钥经 Windows DPAPI 加密保存在本机。

v1.2.3 新增新

触屏更跟手，讲台能转。

这一版专治触控与讲解里的别扭：触摸书写合并中间点后更跟手，双指缩放不再抖，手掌大面积一压就变橡皮；讲台画面可以旋转；导入文件翻页不再卡，页面四周有了边框和翻页条；Dock 可以放大并在图标下显示名称。

讲台画面可以转

讲台底部新增旋转按钮，一下转 90°：0°→90°→180°→270° 循环。画面按旋转后的矩形等比适配，批注坐标跟着一起转；拍照、截图与问 AI 用的都是旋转后的画面。

触摸书写更跟手

触摸与手写笔分开处理：触摸的中间点全部合并，按最小间距去重后再平滑，笔迹不再一顿一顿；绘制合并到每帧一次，慢一点的设备上也不掉帧。

双指缩放不再抽，手掌一压就橡皮

两指一落下就取消单指笔画，缩放增量做了钳制，视图不再抖着乱跳。手写时手掌大面积接触屏幕会临时切成橡皮，接触变小或抬手就切回笔；这个行为在设置里可以关掉。

导入翻页不卡了

背景渲染搬到后台，过期结果直接丢掉，内存里最多缓存 4 页并预取前后页，翻页立即响应。有背景时页面四周多了一圈 1px 边框与柔和投影，下方还有「‹ 第 x / y 页 ›」翻页条。

Dock 能放大，也会报名字

Dock 默认比之前大一点，图标下方直接写着功能名（画笔、橡皮、导入、问 AI……）；「设置 → 工具栏」里的「Dock 大小」可在 0.85–1.40 之间调，窗口太窄时会按可用宽度收回，不遮挡画布。

更新只提示，下载交给浏览器

装的是旧版时点「检查更新」，应用只会提示「发现新版本」；点「查看」打开 GitHub Release 页面，下载和安装都在浏览器里完成——应用内不下载，也不会自动安装。检查顺序是先查 GitHub API，失败再自动切镜像源。

v1.2.2 的全屏 AI 浮窗置顶、关于页 GitHub 直达、更新先问 GitHub、启动不弹恢复提示与一键清除缓存都还在。
