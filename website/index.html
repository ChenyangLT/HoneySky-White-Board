功能

为老师，也为每一个把想法画出来的人。

从一支笔开始，到 AI 讲台答题。每一处细节都为「讲清楚一件事」而设计。

书写与笔触

像笔一样，像纸一样。

笔迹平滑与压感整笔重绘，250 Hz 采样下依然跟手。橡皮可整笔擦除，也可局部擦除；手指绘画默认关闭，避免误触。

  • 压感笔迹与实时光滑
  • 局部擦除 / 整笔擦除两种橡皮
  • 自动化笔迹，随手写就有体面

时间工具新

时钟与倒计时，搬到独立窗口。

时钟与倒计时是始终置顶的独立窗口，不遮挡板书：字号与背景透明度都能调，字号放大后文字依然清晰。

AI 讲台与助手

讲解不再是一个人对着黑板。

把题目交给 AI 讲台：拍下纸张、贴入图片，AI 在白板上边写边讲，支持 LaTeX 公式。日常答疑则交给角落里的 AI 助手浮窗。

AI 功能为可选能力，使用你自己的 OpenAI 兼容接口与 API Key；密钥经 Windows DPAPI 加密保存在本机。

页面与工具

多页白板，工具栏按你的习惯排。

一节课不止一页：缩略图栏随手翻页，缩放与适应窗口一键到位。工具栏里的工具能显示、固定、上下调序，快捷键也可改。

v1.2.1 新增新

打开就是全屏，手不离开画布。

这一版把启动、翻页与页面条又收了一遍：默认进真全屏，右下角多一枚全屏按钮，缩略图显示几个由你决定；顺手修掉橡皮粘手的老问题，关于页与水印的品牌字动画也重做了。

启动即全屏

打开软件直接进入覆盖任务栏的真全屏，屏幕上只剩画布。想退出很简单：点右下角的全屏按钮，或按 Esc / F11。

翻页条上的全屏按钮

右下角翻页条多了一枚全屏按钮，就排在「下一页」之后、缩放与适应窗口之前，讲到一半切进切出不必再翻菜单。

缩略图只留三个

左下页面缩略图条默认只显示 3 个格子，不再一长条压着画布；显示几个能在设置里调，范围 1–8。

橡皮不再粘手

修掉一个会打断板书的 bug：点过橡皮再切直尺或画框时，橡皮不取消、擦除圈跟着鼠标、框也画不出来——这一版彻底解决。

品牌字闪光间隔可调

关于页与白板左上角的 HoneySky 品牌字默认每 5 秒闪白一次，可在「设置 → 动画 → 品牌字闪光间隔」调整 2–30 秒。水印静止态就是品牌橙，与动画同色。

左上角的水印

白板左上角常驻一枚水印：「图标 + 品牌字动画 + 版本号」，静止态是品牌橙，比以前更小更淡，投影时不抢注意力。

v1.2.0 的浮动 Dock、导入为背景、启动动画、更新检测与讲台拍照都还在，可以继续用。
